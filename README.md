# 💼 Flutter Business Registration Form

A clean and modern **Business Registration Form UI** built with **Flutter and Dart**.

I created this project to practice building forms in Flutter while focusing on clean layouts, custom input fields, spacing, and a simple user-friendly interface.

## 📱 Preview

![Business Registration Form](preview/Busniess%20Form.jpeg)

## ✨ Features

* Clean and modern dark UI
* Business registration form
* Custom styled input fields
* Business name, email, username, phone number, country, and ZIP code fields
* Simple submit button
* Registration success message
* Responsive Flutter layout
* Easy-to-understand code structure

## 🛠️ Built With

* **Flutter**
* **Dart**
* **Material Design**

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/hamza-hafeez-dev/flutter-business-registration-form.git
```

### 2. Open the project

Open the project in **Android Studio** or **VS Code**.

### 3. Get Flutter packages

```bash
flutter pub get
```

### 4. Run the project

```bash
flutter run
```
